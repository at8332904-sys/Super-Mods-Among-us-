✅ O que é esse projeto?
 
este projeto é um mod onde tras a nostalgia do among us com funções e mapas da época:
 
- ✅ Funciona em PC e Android  

- ✅ Regiões incluídas: América do Norte, Europa, Ásia + nossa região exclusiva • Super Mods
 
 
 
📋 Requisitos
 
- Versão compatível do Among Us: [COLOQUE A VERSÃO EXATA AQUI, EX: v2026.6.5]

- Android: 11 ou superior

- PC: Windows 10 / 11 64 bits

- Ferramentas recomendadas: MT Manager ou ZArchiver (para Android)
 
 
 
📥 Como instalar e usar
 
🖥️ PC
 
1. Baixe o arquivo ZIP na aba Releases

2. Vai gerar um aplicativo no seu Pc

📱 Android 
 
1. Baixe o APK do Github ou curse forge

2. Permita instalar aplicativos de fontes desconhecidas nas configurações

3. Vai gerar um aplicativo
